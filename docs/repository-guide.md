# How to maintain this portfolio

## Suggested repository name

`technical-projects-portfolio` (or `homelab-and-projects`).

## Editing workflow

1. Create a new GitHub repository and upload **only the contents of `public-github-portfolio`**.
2. Replace contact placeholders in `README.md`.
3. Keep one short, accurate page per project. Prefer proof of a working result over generic tool lists.
4. Include a screenshot or figure when it adds technical context; redact identifiers before upload.
5. For each project, record: **problem → constraints → design → implementation → validation → outcome → next steps**.
6. After publishing, create links to standalone code repositories as those become ready.

## Optional GitHub profile README

If you want this content on your GitHub profile itself, create a separate repository whose name exactly matches your GitHub username and adapt the portfolio summary into that repository's `README.md`. A dedicated project-portfolio repository is usually easier to maintain independently.
